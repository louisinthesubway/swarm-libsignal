# swarm-libsignal Maven repository

A plain Maven repository for Gradle, served from this branch at
`https://raw.githubusercontent.com/Swarm-Official/swarm-libsignal/maven/`.
Artifacts: `org.signal:libsignal-android` and `org.signal:libsignal-client`, SWARM builds of
libsignal with the SWARM network environment. How to use them, and their SHA-256 sums:
docs/SWARM-MOBILE.md on the matching source branch, and the release of the same name as the
version (e.g. swarm-libsignal-0.102.2-swarm.1).

This branch holds build outputs only, written by the "SWARM - Android release" workflow. No
source code lives here.
